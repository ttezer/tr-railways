# TCDD GTFS Static ve Türkiye Demiryolları Haritası — Ray Atlası

Bu depo, TCDD ve TCDD Taşımacılık seferlerinden derlenen bağımsız Türkiye
demiryolları haritasının ve doğrulanmış GTFS Static paketinin yayımlanmış
GitHub Pages çıktısını barındırır. Ray Atlası resmî bir TCDD uygulaması veya
resmî GTFS yayını değildir.

- [Canlı Türkiye demiryolları haritası](https://ttezer.github.io/tr-railways/)
- [TCDD GTFS Static bilgi ve indirme sayfası](https://ttezer.github.io/tr-railways/gtfs/)
- [GTFS Analyzer](https://github.com/ttezer/gtfs-analyzer)

Kaynak kod ve veri üretim araçları ayrı, özel geliştirme deposunda tutulur.

Lisans ve kullanım koşulları için [LICENSE.txt](./LICENSE.txt) ve
[DATA_LICENSE.txt](./DATA_LICENSE.txt) dosyalarına bakın.
